# Gemina 3D — Classical Piano MIDI Archive

Static content-addressed MIDI archive used by [Gemina 3D](https://gemina3d.com).

## License & Attribution

Classical solo piano transcriptions originate from the **GiantMIDI-Piano** dataset:

> Qiuqiang Kong, Bochen Li, Jitong Chen, and Yuxuan Wang, *"GiantMIDI-Piano: A large-scale MIDI dataset for classical piano music"*, Transactions of the International Society for Music Information Retrieval (TISMIR), 2022.
